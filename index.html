番茄钟

开发者： 。

软件简介

一款简洁高效的番茄工作法计时器。帮助你合理规划时间，提升专注力。

主要功能

  • 标准番茄工作法（25分钟专注 + 5分钟休息）
  • 支持自定义专注时长和休息时长
  • 清晰简洁的视觉界面
  • 专注结束提示音
  • 今日专注数据统计

使用

点击下方按钮进入应用，设置专注时长后点击开始即可。

ECG · 心电监护

开发者： 。

软件简介

黑白极简的浏览器心电监护页面。通过 Web Bluetooth 直连心率设备，实时绘制 ECG 波形，每次心跳迸发白色星光。

主要功能

  • Web Bluetooth 直连支持标准 BLE 心率服务（0x180D）的设备
  • 200Hz 采样实时心电图，P/Q/R/S/T 五波叠加
  • 每次 R 峰触发白色星光粒子与涟漪
  • 黑白极简视觉
  • 未连接设备时可切换模拟模式，拖动速度滑块模拟 68–180 BPM
  • 内置兼容设备列表

兼容设备（部分）

华为、Polar、Garmin、Wahoo、小米/Amazfit、Samsung、Apple Watch、Suunto 等支持标准 BLE 心率服务的设备均可连接，部分手表需先在设备端开启心率广播。
